# wariyasu-fetch

「割安ナビ ふるさと納税」(https://furusato.wariyasu-navi.com/)が使う、楽天市場の商品検索 API からふるさと納税の返礼品を取るためのリポジトリです。
Actions の `fetch` が `scripts/fetch.py` を動かし、終わるとサイトの生成(別のリポジトリ)を始めます。

- 取ったデータはこのリポジトリに置きません。成果物(artifact)には暗号化したものだけを置きます(鍵は Secrets)。
- 秘密の値(楽天の API の鍵など)は Secrets にあり、ファイルにはありません。
- `scripts/` はサイトのリポジトリからの写しです(ここでは直しません)。

## 使い方

Actions の `fetch` を手動で実行します。`genres` を空欄にすると全ジャンル、`rice meat` のように書くとそのジャンルだけ取ります(ほかは前回のデータを使います)。

## 権利

コードは割安ナビのものです。転載・再配布はご遠慮ください。商品の情報は楽天グループ株式会社の API から取っています。
